# Repository instructions

## Commit attribution

- When Codex materially changes code, tests, configuration, or documentation,
  append this exact trailer after a blank line at the end of the commit message:

  `Co-authored-by: Codex <codex@openai.com>`

- Keep the repository owner's normal Git author and committer identity.
- Do not add the trailer when Codex only reviews, explains, or inspects without
  changing repository files.
